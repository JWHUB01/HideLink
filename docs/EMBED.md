# Встраивание AnonLink в другие сайты и соцсети

AnonLink можно встроить на любую страницу, которая разрешает `<iframe>`, — так же,
как встраиваются сторонние чаты и виджеты. Встраиваемая версия живёт по адресу
`/embed` и выглядит как обычный AnonLink, но работает в рамке.

## Готовый сниппет

```html
<iframe
  src="https://chat.example.com/embed"
  title="AnonLink — анонимный чат"
  style="width: 100%; height: 720px; border: 0; border-radius: 16px"
  allow="clipboard-write"
  loading="lazy"
></iframe>
```

Замените `chat.example.com` на адрес, где развёрнут AnonLink. Для локальной
проверки: `http://localhost:2100/embed`.

Высота `720px` — разумный старт; ниже показано, как подстраивать её автоматически.

## Автоматическая высота и тема

Виджет сообщает хост-странице о готовности и о каждом изменении высоты, чтобы
рамка не обрезала переписку. Хост может передать виджету тему оформления.

Сообщения виджета (приходят в `window` хост-страницы):

| Поле | Значение |
| --- | --- |
| `source` | `anonlink-widget` |
| `type` | `ready` или `resize` |
| `height` | высота документа в пикселях (для `resize`) |
| `version` | версия протокола, сейчас `1` |

Пример хост-страницы:

```html
<iframe
  id="anonlink"
  src="https://chat.example.com/embed"
  title="AnonLink — анонимный чат"
  style="width: 100%; height: 720px; border: 0"
></iframe>

<script>
  const frame = document.getElementById('anonlink');

  window.addEventListener('message', (event) => {
    const data = event.data;
    if (!data || data.source !== 'anonlink-widget') return;

    if (data.type === 'resize' && Number.isFinite(data.height)) {
      frame.style.height = Math.min(Math.max(data.height, 420), 900) + 'px';
    }
  });
</script>
```

Сообщения хоста (виджет принимает только их, всё остальное игнорирует):

```js
frame.contentWindow.postMessage(
  { source: 'anonlink-host', type: 'theme', theme: 'dark' },
  'https://chat.example.com',
);
```

| Тип | Поле | Допустимые значения |
| --- | --- | --- |
| `theme` | `theme` | `light`, `dark` |
| `shade` | `shade` | `default`, `green`, `purple` |

Тема и оттенок влияют только на цвета. Ни одно сообщение не позволяет прочитать
данные из рамки или выполнить действие от имени пользователя.

## Кто может встраивать

Политика кадров задаётся переменной окружения веб-приложения:

```dotenv
# CSP-список источников, разделённый пробелами. "*" — любая страница.
EMBED_FRAME_ANCESTORS="*"
```

- `*` (по умолчанию) — встраивать может любой сайт. Это режим «виджет для всех».
- Точный список — только перечисленные площадки, например
  `EMBED_FRAME_ANCESTORS="https://vk.com https://web.telegram.org"`.

Заголовок ставится в `apps/web/src/proxy.ts`: `/embed` получает
`Content-Security-Policy: frame-ancestors …`, все остальные страницы —
`X-Frame-Options: DENY`. Кабинет владельца (`/admin`) встраивать нельзя ни при
каких настройках.

Переменная читается в рантайме: после изменения достаточно перезапустить
веб-приложение, пересборка не нужна.

## Как устроена сессия виджета

Обычная сессия AnonLink — это `HttpOnly`-кука. В чужом iframe она была бы
*сторонней* кукой, а такие браузеры не отправляют (Safari и Firefox блокируют их
полностью). Поэтому виджет:

1. получает токен от `POST /api/v1/session/embed` и хранит его в `sessionStorage`
   своей рамки (не в `localStorage` — две вкладки не должны делить личность);
2. передаёт токен в каждом REST-запросе как `Authorization: Bearer …`;
3. передаёт тот же токен в `auth`-поле сокет-хендшейка.

Токен — тот же непрозрачный секрет, что и в куке, меняется только транспорт.
Кука при этом не выставляется: виджет не должен создавать сессию для домена API,
которую могла бы позаимствовать окружающая страница.

Следствия, о которых стоит знать:

- **Свой User ID у каждой рамки.** Новый iframe — новая анонимная личность:
  так и задумано, встраивание не связывает посетителей разных сайтов.
- **Перезагрузка рамки сохраняет сессию**, закрытие вкладки — нет.
- **Требуется HTTPS.** Если хост-страница открыта по HTTPS, браузер не покажет
  в ней `http://`-iframe. Для локальной проверки используйте `localhost`.

## Соцсети

### Обычные сайты, блоги, форумы

 работает сниппет `<iframe>` выше. Если площадка вырезает iframe из постов
(так делают некоторые соцсети), используйте режим мини-приложения.

### Telegram Mini Apps

Мини-приложение Telegram — это веб-страница, открытая во встроенном webview
Telegram. Виджету куки не нужны, поэтому `/embed` подходит как есть:

1. зарегистрируйте бота и мини-приложение в @BotFather;
2. укажите URL приложения — `https://chat.example.com/embed`;
3. добавьте кнопку меню или ссылку `https://t.me/<бот>?startapp`.

Регистрация приложения — шаг в платформе Telegram, а не в коде AnonLink.
Дополнительный SDK Telegram (тема, кнопка «назад», haptic) можно подключить
позже; базовый чат работает без него.

### VK Mini Apps

Аналогично: приложение VK получает URL `https://chat.example.com/embed` и
открывает его в iframe/webview. Нужна регистрация приложения в VK для
разработчиков; произвольные iframe в постах VK не поддерживаются платформой.

### Одноклассники и другие площадки

Схема та же: либо `<iframe>` на странице, либо мини-приложение площадки со
ссылкой на `/embed`. Отдельных SDK в AnonLink нет — виджет самодостаточен.

## Проверка

1. Запустите стек и откройте `http://localhost:2100/embed` — должна открыться
   обычная страница чата.
2. Убедитесь, что заголовок отдаёт `frame-ancestors`, а не `X-Frame-Options`:

   ```powershell
   (Invoke-WebRequest http://localhost:2100/embed -UseBasicParsing).Headers['Content-Security-Policy']
   ```

3. Откройте обычную страницу `http://localhost:2100/` — она по-прежнему отдаёт
   `X-Frame-Options: DENY`.
